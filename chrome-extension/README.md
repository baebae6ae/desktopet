# 데스크토펫 — Chrome 확장 (바이브코딩 프롬프트 도우미)

귀여운 8비트 펫이 **웹페이지 아래쪽을 돌아다니며**, 클릭하면 말풍선
대화창으로 쉬운 질문을 던지고, 다 답하면 **"AI에게 무엇을 요청해야 하는지" 가이드**를
보여줍니다. 아래 **[프롬프트 생성하기]** 버튼을 누르면 답변을 그대로 담아
[nocalhostmore](https://nocalhostmore.vercel.app/) 사이트로 이동해 완성 프롬프트를 만듭니다.

## 특징
- 페이지 하단을 좌우로 걷는 펫(고양이·로봇·유령·슬라임·곰돌이)
- **드래그로 위치 이동** — 공중에서 놓으면 "꺄아악!" 하며 떨어져 바닥에 착지
- 드래그와 클릭을 구분(옮기려고 끌었을 땐 대화창이 뜨지 않음)
- 클릭하면 그 자리에 멈춰 질문 위저드 → 요청 가이드 → 사이트로 유도
- **사이트별 숨기기** — 기본값은 모든 사이트에서 보이고, 특정 사이트에서만 보기
  싫으면 팝업에서 "이 사이트에서 숨기기"를 켜면 그 사이트에서만 예외로 안 나타남
- 팝업에서 전체 켜기/끄기, 캐릭터 변경, 숨긴 사이트 목록 관리
- **가챠** — 프롬프트를 생성할 때마다 코인을 받고, 팝업의 "가챠" 탭에서 빛이 터지는
  뽑기 연출로 머리/얼굴/팔/상체/하체/다리 장착템(코스메틱)을 얻어 캐릭터에
  입힐 수 있음. 장착은 새로고침 없이 바로 펫에 반영됨
- **애착 시스템** — 팝업에서 펫 이름을 지어주면 대사에 이름이 섞여 나오고,
  펫 위에서 마우스를 문질러 쓰다듬으면 하트와 함께 애정도가 쌓임.
  레벨업마다 +20코인, 매일 첫 만남엔 출석 보너스 +30코인
- **페이지와 상호작용** — 화면에 보이는 버튼/이미지 같은 요소 위에 폴짝 올라가
  쿵쿵 구르고(밟힌 요소가 실제로 들썩임), 모서리에서 아래를 빼꼼 내려다보고,
  그 위에서 낮잠도 잠
- **다섯 가지 프롬프트 카테고리** — 펫을 클릭하면 "오늘은 뭘 도와드릴까요?"로
  코딩 프로젝트 · 글쓰기 · 에러 고치기 · 요약·정리 · 이미지 생성 중 고른다.
  **코딩 프로젝트만** 기존 그대로 nocalhostmore로 넘어가고(유입 퍼널), 나머지
  네 카테고리는 그 자리에서 완성 프롬프트를 만들어 바로 복사할 수 있다
  (`vendor/cat-*.js` + `vendor/wizardEngine.js`)

## 설치 (개발자 모드로 불러오기)
아직 웹스토어 미등록 상태에서 테스트하려면:

1. Chrome 주소창에 `chrome://extensions` 입력
2. 우측 상단 **개발자 모드** 켜기
3. **압축해제된 확장 프로그램을 로드합니다** 클릭
4. 이 `chrome-extension` 폴더 선택
5. 아무 웹페이지나 새로고침하면 펫이 바로 나타납니다. 특정 사이트에서만 안 보이게
   하고 싶으면 툴바의 데스크토펫 아이콘을 눌러 **"이 사이트에서 숨기기"**를 켜면
   됩니다(새로고침 없이 바로 사라짐).

> 정식 배포는 Chrome 웹스토어에 이 폴더를 zip으로 올려 심사받으면 됩니다.

## 구조
```
manifest.json          # MV3 매니페스트 (content_script + action popup)
content/
  pet.js               # 콘텐츠 스크립트: 캐릭터 + 로밍/드래그/낙하 + 위저드 대화창
  pet.css              # Shadow DOM 안에 주입되는 스타일
vendor/                # nocalhostmore 로직 재사용 + 캐릭터/가이드
  sprites.js           # 8비트 캐릭터 렌더 데이터(ES 모듈 포팅)
  questions.js         # 질문 모델 (nocalhostmore 원본)
  share.js             # 답변 ↔ URL 프래그먼트 인코딩 (nocalhostmore 원본)
  guideBuilder.js      # 답변 → "요청 가이드" 변환 (코딩 카테고리 전용, 사이트로 넘기기 전 단계)
  gacha.js             # 코인/가챠 확률/보관함·장착 로직(팝업 + 콘텐츠 스크립트 공용)
  wizardEngine.js      # 코딩 외 카테고리가 공용으로 쓰는 위저드 엔진 + 가이드 빌더
  categories.js        # 카테고리 목록(코딩 + cat-*.js 4종) 레지스트리
  cat-writing.js        cat-debug.js / cat-summarize.js / cat-image.js
                       # 카테고리별 질문 + 가이드 + 완성 프롬프트 조립 로직
popup/                 # 켜기·끄기·캐릭터 선택·사이트 열기·가챠 뽑기·장착
icons/                 # 아이콘 (nocalhostmore 브랜드)
```

## 가챠 경제
- 위저드를 끝까지 완주해서 [프롬프트 생성하기]를 누르면 +20 코인
- 뽑기 1회 50코인, 확률은 일반 65% · 레어 27% · 에픽 8%
- 아이템은 장식용이며 6개 슬롯(머리/얼굴/팔/상체/하체/다리)에 하나씩 장착
- 데이터는 `chrome.storage.local`의 `coins` / `inventory` / `equipped` 에 저장

## 퍼널
펫은 최종 프롬프트를 만들지 않습니다(가이드까지만). [프롬프트 생성하기]가
`app.html#s=<답변>` 딥링크로 사이트를 열면, 사이트가 답변을 복원해 곧바로
완성 프롬프트(+광고)를 보여줍니다.
